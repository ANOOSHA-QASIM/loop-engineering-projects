# TODO Fixing Rules

- Sirf simple, safe TODOs khud fix karo (jaise: agar input negative ho to error throw karna, string check karna)
- Agar TODO complex lage (jaise: business logic ka decision chahiye ho), to khud mat karo — progress.md mein "NEEDS HUMAN" likh do
- Har fix ke baad naya function purane jaisa hi kaam kare (backward compatible ho)
